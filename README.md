# IPA Installer

Своя программа для Windows (Python + tkinter), которая ставит IPA на iPhone по USB.
Подписывает IPA твоим сертификатом (по желанию) и устанавливает на телефон.

## Что нужно
- Windows с **iTunes** или приложением **Apple Devices** (из Microsoft Store): в них есть драйвер USB для iPhone.
- iPhone, подключённый кабелем, разблокированный, с нажатым «Доверять этому компьютеру».
- IPA, который **уже подписан** для твоего устройства, либо твои `.p12` + пароль + `.mobileprovision`
  (аккаунт разработчика Apple, $99 в год; UDID телефона должен быть в профиле).

## Сборка .exe без установки Python
1. Загрузи папку в репозиторий GitHub.
2. **Actions** → **Build Windows exe** → **Run workflow**.
3. Скачай артефакт `IPAInstaller-windows` (внутри `IPAInstaller.exe`).

## Подпись внутри программы
Подпись делает внешняя утилита [zsign](https://github.com/zhlynn/zsign). Готовых сборок
у неё нет: собери `zsign.exe` по её инструкции (Visual Studio 2022) и положи рядом с `IPAInstaller.exe`.
Если IPA уже подписан, zsign не нужен: просто сними галочку «Подписать».

## Запуск из исходников
```
pip install -r requirements.txt
python app.py
```

## Чего пока нет
Подписи через Apple ID без платного аккаунта (как в Sideloadly) и автопродления через 7 дней.
Это отдельный большой кусок работы: нужен вход в Apple ID с двухфакторкой и запросы к закрытым
сервисам Apple.

Статус: код проверен только на уровне логики (работа с файлами, обработка ошибок). Установку на
реальный iPhone я проверить не мог, так что первый запуск — тестовый.
